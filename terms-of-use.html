Description of Service

ElectriCalc is a professional electrical calculation tool that provides wire sizing, voltage drop, ampacity, conduit fill, box fill, load calculation, derating, motor sizing, transformer sizing, and ground wire sizing calculations based on the National Electrical Code (NEC) and Canadian Electrical Code (CEC).
